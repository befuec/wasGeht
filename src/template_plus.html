🔒 Datenschutz

Eure Einträge werden auf diesem Gerät mit dem Familien-Code verschlüsselt und erst dann in der Datenbank (Supabase, EU) gespeichert. Der Server sieht nur unlesbare Daten – nicht einmal, welche Ausflüge oder Aufgaben ihr habt. Den Code selbst bekommt niemand: Gespeichert wird nur ein daraus berechneter Schlüssel.

Keine Werbung, kein Tracking, keine Cookies. Schriften liegen auf dieser Seite selbst; nur das Wetter wird bei Open-Meteo abgefragt (ohne eure Daten). Gelöschtes bleibt 30 Tage im Papierkorb, wöchentliche Sicherungen 4 Wochen. Erledigte Haushalts-Haken älter als ein Jahr werden zu Monatssummen zusammengefasst.

⚠️ Familie und alle Daten löschen

Löscht eure Familie samt allen Einträgen, Papierkorb und Sicherungen endgültig aus der Datenbank – für alle Geräte. Das kann nicht rückgängig gemacht werden. Zum Bestätigen LÖSCHEN eintippen.

Familien-Code eingeben

Damit sind Ausflugsplan, Aufgaben und Punkte auf allen euren Handys gleich – und nur für eure Familie sichtbar.

Denkt euch einen Code aus (mindestens 12 Zeichen, am besten drei Wörter wie „Elbe-Kastanie-Laterne“) und gebt ihn danach an die anderen in der Familie weiter. Eure Daten werden mit diesem Code auf dem Handy verschlüsselt – niemand sonst, auch nicht der Server, kann sie lesen. Geht der Code verloren, sind die Daten nicht mehr lesbar: gut merken!
